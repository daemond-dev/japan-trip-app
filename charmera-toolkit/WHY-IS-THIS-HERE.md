# Why is a camera toolkit in the Japan trip app repository?

Temporary home. The toolkit was built in a cloud session whose GitHub access covered only this repository and
daemond-dev.github.io, and the push to daemond-dev.github.io was refused (the Claude GitHub App is not installed
there). This branch keeps the work from being lost. Move the `charmera-toolkit/` directory to its own repository
and delete this branch; nothing here is referenced by the trip app.
